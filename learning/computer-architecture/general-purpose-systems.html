通用计算系统 ​

体系结构关心的不只是“处理器怎么接线”，还包括给定工作负载、面积、功耗与软件条件，为什么这样设计更合适。建议先理解指令集架构（Instruction Set Architecture，ISA）和微架构的区别，再学习流水线、存储层次与并行计算。硬件实现基础见 数字电路自学。

入门：连起程序与硬件 ​

资源类型难度说明
UCB CS61C公开课入门—进阶以 C、汇编、数据表示、处理器和存储层次连接软件与硬件
Patterson、Hennessy《Computer Organization and Design》教材入门—进阶建议选择 RISC-V 版本；结合手算时序图与小程序学习
CMU 18-447体系结构课程进阶通过流水线处理器和存储系统加深设计理解；各学期公开材料范围不同
RISC-V International官方规范入口入门—深入从所用整数 ISA、异常与特权机制查起，明确规范版本及扩展集合

不要把 ISA 模拟器能执行程序，等同于硬件微架构正确。先明确指令语义，再检查取指、译码、执行、访存和提交之间的关系。对于流水线，必须解释数据冒险、控制冒险、旁路与停顿；对于 Cache，必须区分容量、行大小、相联度与缺失代价。

进阶：学习定量方法 ​

资源类型难度说明
UCB CS152体系结构课程进阶扩展到现代处理器、存储系统与设计权衡，先检查所选学期先修要求
Hennessy、Patterson《计算机体系结构：量化研究方法》教材进阶—深入不仅看结论，要复算工作负载、性能、能耗与成本之间的比较
Roofline（Williams、Waterman、Patterson，2009）经典论文进阶用运算强度、带宽与峰值算力判断计算或访存瓶颈
Amdahl's Law in the Multicore Era（Hill、Marty，2008）经典论文进阶在资源约束下讨论并行比例与多核配置，避免只追求核心数量
The Optimum Pipeline Depth for a Microprocessor（Hartstein、Puzak，2002）经典论文进阶理解流水深度、锁存开销与停顿之间的权衡
gem5架构模拟平台进阶—深入可做 CPU、Cache 等设计空间探索，但必须说明模型、参数、预热与统计区间

进一步可读乱序处理器机理模型、GPU 的 MWP/CWP 模型、LogCA，以及 DNN 加速器的 Timeloop / Accelergy。它们解决的问题和精度不同，不宜把模型预测直接写成芯片实测性能。阅读论文时记录“假设了什么、输入是什么、在哪些负载下验证、哪些机制没建模”。

实践：选择一个开源系统读进去 ​

资源类型难度说明
Rocket ChipRISC-V SoC 生成器进阶适合研究参数化核、总线、Cache 与系统集成，先从默认配置读起
BOOM乱序 RISC-V 核深入关注重命名、发射、重排序与恢复，宜先理解顺序流水线
XiangShan高性能 RISC-V 处理器深入面向复杂微架构与工程验证，不建议作为第一次 HDL 项目
Vortex开源 GPU 项目进阶—深入学习 SIMT、线程调度、访存及软硬件接口
Ventus开源 GPGPU 项目进阶—深入可用于研究 RISC-V 相关 GPU 栈；按项目支持范围准备编译与运行环境

第一次实验不必修改大型处理器。可以固定一组小程序，用 gem5 改变 Cache 容量或相联度，记录执行时间、缺失率与访存统计；或者在已有教学核中加入一种旁路并比较 CPI。一次只改一个主要变量，同时记录输入、编译参数、模型配置和版本。IPC 更高不一定程序更快，频率与工作量也必须一致或明确交代。
