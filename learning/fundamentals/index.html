基础知识 ​

基础的作用是让后续学习不卡住，而不是增加一张必须全部刷完的清单。数字设计优先补二进制、C、命令行和时序概念；模拟与器件方向优先补微积分、线性系统和数值计算；EDA 与 AI 硬件还需要概率、矩阵和优化。先看 学习地图，再按当前任务选择。

入门：数学和编程能用起来 ​

资源类型难度说明
MIT 18.06 Linear Algebra（MIT OCW）公开课入门重点是线性方程组、子空间、特征值、正交投影；理解矩阵运算在表达什么
MIT 6.041 概率课程（MIT OCW）公开课入门—进阶先掌握条件概率、随机变量、期望与方差，再学随机过程
Oppenheim《Signals and Systems》及 MIT 相关课程教材、公开课入门—进阶卷积、傅里叶变换、拉普拉斯变换与系统响应是电路和信号处理的共同语言
Kernighan、Ritchie《The C Programming Language》教材入门配合小程序学习指针、数组、结构体、位操作；另查现代编译器与安全用法
Python 官方文档教程、参考入门用于数据处理、批量实验和报告自动化，不必一开始追求复杂框架
NumPy、Matplotlib数值与绘图库入门用实际数组、误差曲线和波形巩固数学概念

一个实用练习是：用 C 实现定宽整数运算，再用 Python 生成边界输入并比较结果。注意 C 的有符号溢出、移位范围与硬件定宽截断并不自动等价。数学练习则可从离散卷积和 RC 阶跃响应开始，对照手算、数值结果与物理单位。

进阶：熟悉每天都会用的工具 ​

资源类型难度说明
MIT Missing Semester工具公开课入门—进阶Shell、数据整理、编辑器、Git、调试与性能分析；优先学与当前项目有关的章节
GNU BashShell 文档入门—进阶掌握引号、变量、管道、重定向与退出码，读懂实验脚本
Git 与 Pro Git官方文档、电子书入门从 status、diff、提交和分支开始，不把远程仓库当作临时文件同步盘
Vim 与 vimtutor编辑器教程入门会进入编辑、保存退出、搜索替换即可开始；不必先定制复杂配置
GNU Make构建工具文档进阶用目标、依赖和配方表达构建关系，减少手动复制命令
GDB调试器文档进阶学断点、调用栈和变量检查，替代只靠反复打印猜错误

能在本地桌面点击运行，还不代表能在服务器复现实验。请练习从一个干净目录开始：找到输入、设置路径、运行命令、检查退出码、定位日志。使用相对路径组织项目；依赖版本和运行说明写在项目内，而不是只保存在自己的 Shell 历史中。

实践：做一个可重复的小实验 ​

资源类型难度说明
EDA 环境与 Linux操作指南入门常用命令、远程环境、作业调度及数据保密规范
数字电路资源后续路线入门—进阶将编程与命令行技能用到硬件仿真
EDA 算法资源后续路线进阶将矩阵、图算法和实验统计用于优化问题

建议项目：用 Python 生成一组 RC 电路输入，分别用解析公式和数值方法求响应；保存参数、误差和曲线。用 Make 管理生成与绘图，用 Git 记录源码与参数。成功标准是其他人按说明能复现，而不是只在你的电脑上生成过一张图。

开始下一阶段前，检查自己能否解释：标准输出与标准错误的区别、相对路径从哪里算起、一个进程为何失败、矩阵每一维代表什么、数值误差是否足以改变结论。缺项可以边做边补，无需因为工具不熟而推迟所有专业课学习。
