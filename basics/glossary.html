常用术语表 ​

查术语时，先看它属于哪个抽象层。同一个缩写在不同领域可能有不同含义；本页采用芯片学习中常见的用法，不替代课程中的严格定义。理解流程可看 芯片设计全流程，遇到课程代码则查 课程总览。

器件、材料与工艺 ​

缩写英文全称中文一句话解释
ICIntegrated Circuit集成电路将器件和互连集成在半导体等基底上形成的电路。
MOSFETMetal-Oxide-Semiconductor Field-Effect Transistor金属氧化物半导体场效应晶体管通过栅极电场调节沟道电流的晶体管。
CMOSComplementary Metal-Oxide-Semiconductor互补金属氧化物半导体使用互补型 MOS 器件实现电路的技术。
NMOSN-Channel MOSN 沟道 MOS以电子作为沟道主要载流子的 MOS 器件。
PMOSP-Channel MOSP 沟道 MOS以空穴作为沟道主要载流子的 MOS 器件。
BJTBipolar Junction Transistor双极结型晶体管依靠双极载流子输运工作的晶体管。
FinFETFin Field-Effect Transistor鳍式场效应晶体管使用鳍形沟道增强栅极控制的器件。
GAAGate-All-Around环栅结构栅极环绕沟道以增强静电控制的结构。
CFETComplementary Field-Effect Transistor互补场效应晶体管常指将互补型器件垂直集成的结构路线。
SOISilicon on Insulator绝缘体上硅在绝缘层上形成硅器件层的材料结构。
GaNGallium Nitride氮化镓可用于功率与高频器件的宽禁带半导体。
SiCSilicon Carbide碳化硅可用于高压功率器件等领域的宽禁带半导体。
SCEShort-Channel Effects短沟道效应沟道缩短后出现的一组偏离长沟道行为的效应。
DIBLDrain-Induced Barrier Lowering漏致势垒降低漏极电压影响源端势垒而改变器件行为的效应。
CVDChemical Vapor Deposition化学气相沉积通过气相化学反应在表面形成薄膜的工艺。
ALDAtomic Layer Deposition原子层沉积通过自限制表面反应逐层形成薄膜的工艺。
CMPChemical Mechanical Polishing化学机械抛光综合化学与机械作用实现表面平坦化的工艺。
EUVExtreme Ultraviolet极紫外在先进光刻中使用的短波长光技术类别。
BEOLBack End of Line后道互连工艺器件形成后构建互连等结构的制造阶段。
FEOLFront End of Line前道器件工艺在晶圆上形成晶体管等器件的制造阶段。

数字设计与验证 ​

缩写英文全称中文一句话解释
RTLRegister-Transfer Level寄存器传输级用寄存器状态及其间数据转换描述同步硬件的抽象层。
HDLHardware Description Language硬件描述语言用于描述硬件结构与行为的语言。
SVSystemVerilogSystemVerilog 语言扩展 Verilog、支持设计与验证的标准语言。
FSMFinite-State Machine有限状态机用有限状态和转移规则描述控制行为的模型。
FFFlip-Flop触发器按时钟事件保存状态的时序元件。
CDCClock Domain Crossing跨时钟域信号在不同时钟域之间传递的问题。
RDCReset Domain Crossing跨复位域不同复位关系之间信号交互的问题。
UVMUniversal Verification Methodology通用验证方法学基于 SystemVerilog 的可复用验证方法与类库体系。
SVASystemVerilog AssertionsSystemVerilog 断言描述并检查设计性质和时序关系的语言机制。
BMCBounded Model Checking有界模型检查在有限展开深度内寻找性质反例的形式方法。
DFTDesign for Testability可测性设计在设计中加入结构以提高制造后测试能力。
ATPGAutomatic Test Pattern Generation自动测试向量生成针对故障模型自动生成测试激励。
BISTBuilt-In Self-Test内建自测试由芯片内部逻辑生成或检查测试的技术。
MBISTMemory Built-In Self-Test存储器内建自测试面向片上存储器的内建测试技术。
ECOEngineering Change Order工程变更在已有实现上进行受控修改以修复或优化设计。

综合、物理实现与签核 ​

缩写英文全称中文一句话解释
EDAElectronic Design Automation电子设计自动化支持电路设计、验证与实现的软件方法体系。
PDKProcess Design Kit工艺设计套件将某项制造工艺的模型和规则提供给设计端的数据集合。
PPAPower, Performance, Area功耗、性能、面积评价设计取舍的一组常用指标。
P&RPlacement and Routing布局布线决定单元位置并完成物理连线的过程。
CTSClock Tree Synthesis时钟树综合构造时钟分配网络并控制其延迟与偏斜。
STAStatic Timing Analysis静态时序分析基于时序图和约束检查路径时序的方法。
SDCSynopsys Design Constraints设计约束格式描述时钟和时序例外等约束的常用命令格式。
SDFStandard Delay Format标准延迟格式交换并回标单元或互连延迟等信息的格式。
SPEFStandard Parasitic Exchange Format标准寄生交换格式表达互连寄生电阻电容等参数的格式。
LEFLibrary Exchange Format库交换格式描述工艺层及单元抽象物理信息的格式。
DEFDesign Exchange Format设计交换格式交换布局布线等设计物理信息的格式。
GDSIIGraphic Data System II版图数据格式交付和交换版图几何图形的常用格式。
DRCDesign Rule Check设计规则检查检查版图几何是否符合工艺规则。
LVSLayout Versus Schematic版图原理图一致性检查比较版图提取电路与原理图或网表的连接关系。
PEXParasitic Extraction寄生参数提取从物理版图估计互连等产生的寄生参数。
PVTProcess, Voltage, Temperature工艺、电压、温度描述设计分析条件的主要维度。
OCVOn-Chip Variation片上变异同一芯片不同位置器件与路径参数的变化。
EMElectromigration电迁移电流作用下金属原子迁移引起的可靠性问题。
SISignal Integrity信号完整性研究耦合、反射等因素对信号质量的影响。

模拟、射频与测量 ​

缩写英文全称中文一句话解释
ADCAnalog-to-Digital Converter模数转换器将连续模拟信号转换成数字表示的电路。
DACDigital-to-Analog Converter数模转换器将数字码转换成模拟输出的电路。
PLLPhase-Locked Loop锁相环利用反馈使输出相位或频率跟踪参考的系统。
LDOLow-Dropout Regulator低压差线性稳压器在较小输入输出压差下工作的线性稳压电路。
LNALow-Noise Amplifier低噪声放大器用于接收链路前端并尽量少引入噪声的放大器。
PAPower Amplifier功率放大器为负载或天线提供较大信号功率的电路。
SNRSignal-to-Noise Ratio信噪比信号功率与噪声功率之比。
ENOBEffective Number of Bits有效位数将转换器实际性能折算为理想量化位数的指标。
CMRRCommon-Mode Rejection Ratio共模抑制比衡量电路抑制共模输入能力的指标。
PSRRPower Supply Rejection Ratio电源抑制比衡量电源变化耦合到输出程度的指标。
GBWGain-Bandwidth Product增益带宽积在适用模型下刻画放大器增益与带宽关系的指标。
ATEAutomatic Test Equipment自动测试设备对芯片施加激励并自动采集判定结果的设备。

系统、存储与产业 ​

缩写英文全称中文一句话解释
SoCSystem on Chip片上系统集成计算、存储、互连与接口等功能的芯片系统。
ISAInstruction Set Architecture指令集架构定义机器指令及软件可见行为的接口规范。
CPUCentral Processing Unit中央处理器执行通用指令流的计算单元。
GPUGraphics Processing Unit图形处理器适合大规模并行工作负载的处理器类别。
NPUNeural Processing Unit神经网络处理器面向神经网络运算优化的处理单元类别。
FPGAField-Programmable Gate Array现场可编程门阵列制造后仍可配置逻辑与互连的可编程芯片。
ASICApplication-Specific Integrated Circuit专用集成电路面向特定应用设计的集成电路。
SRAMStatic Random-Access Memory静态随机存储器依靠双稳态电路保存数据、上电时无需刷新的一类存储器。
DRAMDynamic Random-Access Memory动态随机存储器依靠电荷存储并需要周期刷新的存储器。
HBMHigh Bandwidth Memory高带宽存储器采用堆叠与宽接口提供高带宽的存储技术。
MRAMMagnetoresistive Random-Access Memory磁性随机存储器利用磁性状态及磁阻效应读写信息的存储器。
CIMCompute-in-Memory存内计算在存储阵列内或紧邻阵列完成部分计算的技术。
NoCNetwork on Chip片上网络连接片上模块并传输数据的网络化互连。
CPOCo-Packaged Optics光电共封装将光学引擎与电子芯片在封装层面紧密集成。
TSVThrough-Silicon Via硅通孔穿过硅基底以实现垂直电连接的结构。
IPIntellectual Property知识产权核在芯片语境中常指可授权复用的设计模块。
IDMIntegrated Device Manufacturer垂直整合制造商同时具有芯片设计与制造等业务的企业。
OSATOutsourced Semiconductor Assembly and Test外包半导体封装测试向其他芯片企业提供封装与测试服务的业务类别。
MPWMulti-Project Wafer多项目晶圆多个设计共享同批晶圆制造资源的服务方式。
NRENon-Recurring Engineering非重复性工程费用项目中不随每颗芯片重复发生的研发等费用。

使用提醒 ​

同一页报告里，SI 也可能表示国际单位制，IP 也可能指网络协议。缩写必须服从上下文。PPA、良率、吞吐、能效等指标还需要说明测量范围与条件：芯片核心、整个裸片、开发板和整机的结果不能直接混用。
