数字电路自学 ​

数字电路不是把软件代码换一种语法。硬件描述语言（Hardware Description Language，HDL）描述并行电路，寄存器在时钟边沿更新，组合路径有延迟。推荐顺序是逻辑概念 → 小模块 HDL → 测试平台 → 时序分析 → 系统集成。可与 数字学习地图 配合使用。

入门：先会描述和检查小电路 ​

资源类型难度说明
HDLBits在线练习入门从组合逻辑、计数器到有限状态机；做完后画出对应电路，而非只记录通过状态
Harris、Harris《Digital Design and Computer Architecture》教材入门—进阶把逻辑、HDL 与处理器数据通路串起来；选择与自己指令集目标匹配的版本
Verilog / SystemVerilog 语言基础语言与规范入门—进阶优先掌握位宽、符号、阻塞与非阻塞赋值、组合与时序过程；语言标准可从 Accellera 查找入口
MIT 6.191（原 6.004）数字系统课程入门—进阶自底向上学习逻辑、状态机与处理器；Computation Structures 保留旧版公开材料

每个练习都问三个问题：这里需要几个寄存器？复位后状态是什么？输出在哪个周期有效？特别检查位宽扩展、默认赋值、锁存器推断与复位优先级。测试要覆盖连续输入、空闲间隔和边界情况，不要只用一条“正常路径”。

进阶：从语法走向可实现的系统 ​

资源类型难度说明
UCB EECS151数字设计与集成电路课程进阶连接 RTL、存储模块、流水线、FPGA / ASIC 方法与物理约束
Verilator编译型仿真工具进阶适合构建较大的自动化回归；注意支持的语言特性与时间模型需查当前文档
cocotbPython 验证框架进阶用参考模型、随机输入和自动检查测试 HDL；底层仍需支持的仿真器
ChiselScala 硬件构造语言进阶适合参数化与生成式设计；先能读生成 RTL，再学习抽象与组件化
SpinalHDLScala 硬件构造语言进阶可用于总线、流水线及接口组织；同样不能绕过 HDL 与时序基础

SystemVerilog 不等于完整验证环境，Chisel / SpinalHDL 也不等于自动获得正确电路。初学者宜先用一种语言完成模块与验证，再因参数化或工程需求引入生成器。综合后检查资源与关键路径；功能仿真通过不能证明时序满足要求，更不能证明跨时钟域（Clock Domain Crossing，CDC）安全。

实践：先仿真，再上板，最后扩成系统 ​

资源类型难度说明
开源仿真工具链本地实验入门Icarus Verilog 与波形查看器足以开始计数器、状态机和 FIFO 实验
Digilent 等厂商的 FPGA 开发板资料板卡与参考设计入门—进阶选有原理图、引脚约束、时钟说明和工具支持的板卡，优先使用课程指定硬件
FPGA 厂商工具与板卡手册工程实践进阶AMD Vivado、Intel Quartus 等依目标器件选择；烧录前检查电平、引脚与复位
一生一芯处理器与系统项目进阶—深入连接 C、指令集、处理器、验证与系统软件，参见 项目介绍

建议第一项作品是同步 FIFO：明确容量、满空行为、同时读写规则；写参考队列与自动比较；覆盖复位、绕回和满空边界。第二项再做 UART 或简单处理器。FPGA 上板前先完成仿真，上板后记录约束、时钟频率和时序报告；LED 亮了只是一个观察，不是完整功能验证。
