# 贡献者与署名

网站的文字、校对、工具维护和资源推荐都来自社区。读者可以沿公开记录了解一篇文章如何形成。

## 查找贡献记录

- [已合并的 Pull Requests]({{ repo_url }}/pulls?q=is%3Apr+is%3Amerged)记录每次修改的说明、提交和讨论。
- [议题列表]({{ repo_url }}/issues)保留公开的选题、纠错与资源推荐记录。
- [仓库贡献者]({{ repo_url }}/graphs/contributors)按 Git 提交展示参与者。校对意见、讨论和资料推荐也可以通过对应的议题或合并请求追溯。

## 如何为资料署名

引用他人内容时，请在相关段落或图表附近注明作者、标题、来源与许可。改编材料还应说明改动。署名名称请尊重原作者的选择。

若发现漏署或误署，请在[错误反馈]({{ repo_url }}/issues/new/choose)中提交页面位置、原始材料与建议修改方式。
