# 社区与共建

上科大芯知库（ShanghaiTech IC Wiki）由学生发起。你可以从修正一个术语、推荐一份公开资源或认领一个待共建页面开始。

## 参与方式

| 我想做什么 | 从这里开始 |
| --- | --- |
| 交流学习问题、讨论选题、寻找合作者 | [GitHub Discussions（社区讨论）]({{ repo_url }}/discussions) |
| 报告问题、推荐资源、提交文章 | [参与共建](contributing.md) |
| 查看 Markdown、公式、代码与图表的写法 | [文章写作示例](writing.md) |
| 查阅贡献记录、为引用的材料署名 | [贡献者与署名](contributors.md) |
| 接手站点构建、发布或迁移 | [站点维护](maintenance.md) |

还没有准备好写文章？在[议题列表]({{ repo_url }}/issues)里补充一个失效链接的替代来源，也能帮助读者。
