# 关于本站

ShanghaiTech IC Wiki 是由上海科技大学学生维护的集成电路学习 Wiki。我们希望把课程、科研方向、教授与课题组、平台、培养项目和成长经验连成一张可用的地图，让刚入门的同学知道从哪里开始，也让已有方向的同学更容易查漏补缺。

## 缘起：把公开信息与学生经验连起来

我们参考并致敬 [NJU「集成全家桶」](https://njuic-students.github.io/)、[IC 自学指南](https://crys-chen.github.io/ic-guide/)与 [CS 自学指南](https://csdiy.wiki/)。这些项目展示了一种值得学习的方式：把零散资源组织成路径，把个人走过的弯路整理成可以持续修正的公共知识。

本站不想再写一遍互联网上已有的全部 IC 教材。对于通用知识，我们尽量给出简洁解释、先修关系和可靠入口；更希望把时间用在**上科大独有信息**上：哪些课程能够接起来、哪些老师公开从事什么方向、有哪些可利用的平台和培养项目，以及不同年份的真实学习经验。

参考不等于复制。外校的培养方案、选课规则和经验不能直接移植到上科大；他站的文字、图片与资料也各有版权。我们以自己的组织和说明连接资源，引用时注明出处，不因“网上能找到”就重新分发。

## 事实、建议与经验分开写

课程、招生、导师、平台等事实以官方资料为依据，年份与适用范围尽量写清楚；学习路线是编辑建议；往届经验是特定时间、特定条件下的记录。三者不能互相替代。我们不编造教师经历，不评价个人性格，也不提供“保证录取”“一定进组”等承诺。

发现不确定内容，宁可缩小结论或请读者查官网，也不补上一个看似完整的答案。页面过时不可避免，重要决策请回到最新官方文件。你可以通过[参与建设](/about/contribute)提出有来源的纠错，不需要等到写完一整篇文章。
