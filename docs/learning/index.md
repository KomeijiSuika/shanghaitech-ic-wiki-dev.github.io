# 学习地图

可以从需要补齐的基础出发，也可以从想完成的小项目倒推。每条路线将记录先修知识、学习材料，以及用来检验自己是否学会的小任务。

## 选择一条路线

| 路线 | 拟回答的问题 |
| --- | --- |
| [基础知识](fundamentals/index.md) | 学电路、信号与数字逻辑分别需要哪些准备？ |
| [数字集成电路](digital-ic/index.md) | 如何从逻辑功能描述走到验证与综合？ |
| [模拟集成电路](analog-ic/index.md) | 如何把电路指标与分析、仿真对应起来？ |
| [器件与工艺](devices-and-process/index.md) | 如何联系器件结构、工艺步骤与电学特性？ |
| [电子设计自动化](eda/index.md) | 一个芯片设计任务如何变成算法问题？ |
| [计算机体系结构](computer-architecture/index.md) | 如何用程序和测量理解处理器的行为？ |
