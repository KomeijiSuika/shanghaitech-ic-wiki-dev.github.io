# 学习地图

可以从需要补齐的基础出发，也可以从想完成的小项目倒推。每条路线将记录先修知识、学习材料，以及用来检验自己是否学会的小任务。

如果需要先补数学、电路或信号方面的先修知识，可以从[基础知识](fundamentals/index.md)开始。

## 专业方向

| 方向 | 学习入口 |
| --- | --- |
| [工艺与器件](devices-and-process/index.md) | 制造步骤和器件结构如何影响电学特性？ |
| [电路](circuits/index.md) | [模拟和射频电路](analog-ic/index.md)关注增益、噪声和阻抗匹配。[数字电路](digital-ic/index.md)关注逻辑、时序和验证。 |
| [系统架构](computer-architecture/index.md) | [通用计算系统](computer-architecture/general-purpose-systems.md)关注处理器与存储层次。[领域专用与异构系统（AI系统）](computer-architecture/heterogeneous-systems.md)关注专用加速和多种计算单元的协作。 |
| [算法与编程](algorithms-and-programming/index.md) | [编程语言与软件工程](algorithms-and-programming/languages-and-software-engineering.md)关注程序的实现、测试与维护。[算法与计算理论](algorithms-and-programming/algorithms-and-computation-theory.md)关注问题能否求解及求解的代价。 |
| [EDA](eda/index.md) | 如何把芯片设计中的综合、布局或布线任务转化为算法问题？ |

各方向的学习路线均待共建。可以使用[学习路线模板]({{ repo_url }}/blob/main/templates/learning-roadmap.md)注明教材版本、适用章节和先修要求，帮助下一位读者决定从哪里开始。
