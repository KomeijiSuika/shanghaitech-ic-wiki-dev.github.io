文章写作示例 ​

下面用时钟周期换算演示一篇短文怎样组合公式、代码和图表。点击页面底部的编辑链接可以查看完整 Markdown 源码。

公式与单位 ​

行内公式用单个美元符号包围，例如 $f = 1/T$ 显示为 f=1/T。独立公式在上下两行各写一对美元符号。

T=1f

f 表示频率，单位为赫兹（Hz）。T 表示周期，单位为秒（s）。

可复制的代码 ​

代码块开头标注语言，例如 ```python。这段 Python 示例使用 MHz 表示频率、ns 表示周期，运行结果应为 10 ns。

python
frequency_mhz = 100
period_ns = 1000 / frequency_mhz
print(f"{period_ns:g} ns")

对照表 ​

Markdown 表格可以让读者用一组已知输入复核计算。

单位约定

做数量级检查时，记住 1 MHz 对应的周期为 1 µs。在公式和代码里使用相同的单位约定。

提示、限制和折叠内容分别用 ::: tip、::: warning、::: details 容器；经验征集统一用 ::: info 征集，见参与共建。

避免被 Vue 误解析 ​

VitePress 会把 Markdown 编译为 Vue 组件，正文里的双花括号会被当作模板插值。需要展示这类语法时，把它放进代码块或行内代码；裸写的 < 与 HTML 片段也应放进代码中。提交文章前，可以沿参与共建中的流程运行 npm run build 检查。
